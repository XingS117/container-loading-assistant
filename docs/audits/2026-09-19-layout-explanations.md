# 布局解释与有界整排优化验收

## 改动与边界

新增每方案目标、求解状态、硬约束、未满足软目标以及相对当前高装载率的件数/步骤/重心/距离/空白差异。空白按同高度包围范围减去货物投影并集计算，含边缘凹口；不把空白等同于悬空。直接支撑独立统计。复杂分析达到上限时明确返回未完整评估，不填假零。

结果可跳转到对应分层和空白区域，打印包含相同解释。人工调整后采用后端重新计算的几何指标，清除旧推荐承诺和风险选区。历史中缺少解释时显示缺失，结构损坏的历史不加载且不覆盖原存储。

整排优化仅适用于不超过 200 件、2 至 24 行且存在上层空白的未锁定方案，最多 96 个换位候选、每方案最多 1.5 秒并受主计算剩余预算约束。保持身份/件数/尺寸/朝向/重量和柜门预留，不增加卸货顺序逆序，不恶化同层或混合高度上层连续性及前后/左右重心，最终仍执行物理校验。高装载率方案不改动；易操作按步骤、SKU 切换和距离取舍。
