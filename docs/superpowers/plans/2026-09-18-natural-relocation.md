# 自然搬移与紧凑结果页

目标：解除原高度锁定造成的编辑死锁，缩短画布与视图切换按钮的距离。

设计：结果画布高度独立于右侧内容，右侧折叠步骤/明细/提示并独立滚动。移动保留柜内水平限位，自动选择目标最高接触面；原货位失去支撑的货物向下归位。接近同规格承载面时水平吸附。完整结果经过几何检查及后端安全复核才一次写入，可整体撤销；不改变尺寸、数量或锁定货物。精确坐标输入继续严格检查，不自动修改指定高度。

- [x] 为上层落地、底层抽出后归位、目标堆叠吸附、锁定及越界增加失败测试。
- [x] 实现 workbench.ts 搬移与落位，接入按钮、二维及三维预览；增加三维货物直接拖动。
- [x] 固定结果画布适应屏幕高度，右侧明细折叠；移动端保持单列。
- [x] 运行前端测试、构建和后端校验测试；浏览器检查多 SKU 堆叠、桌面与窄屏。

发布步骤：提交、推送、备份部署及公网验证，结果以发布操作记录为准。

不包含：柜外暂存、删除货物、动态搬运路径或运输稳定性仿真。柜外拖动仍限位。涉及其他货物下降时告知数量；所有修改可撤销。

## 验证结果

- `npm test -- --run`：65 项通过，包含搬移、联动归位、锁定、整组、边界、局部支撑、原位无操作与撤销回归。
- `npm run build`：通过；存在既有的大包体积提示。
- `.venv/Scripts/python.exe -m pytest backend/tests/test_layout_review.py backend/tests/test_validator.py -q -p no:cacheprovider`：18 项通过。
- Chromium 使用五 SKU 55 托预置案例，各 SKU 测试单重 200kg（并非用户实际重量）。1440×900 下明细展开不再拉高画布，步骤按同一步同 SKU 合并，刷新后无控制台错误。
- 三维直接拖动 ZT1 第 17 件，从 Z=110cm 移到空白处后落地；Esc 取消没有提交修改。
- 从地面输入目标 X=684cm/Y=142cm 自动落位，吸附至 X=680cm/Y=140cm/Z=110cm；撤销恢复地面位置。
- 移动原底层 ZT1 第 8 件到 X=1000cm/Y=0cm，其上第 17 件向下归位；后端复核通过。
- 390×844 下检查结果页、编辑入口与侧栏开关，修复编辑按钮无文字和操作行换行问题。

操作说明：拖动或“按 X / Y 自动落位”负责搬移；“预览坐标”仍严格按 XYZ 检查。红色预览表示几何检查不通过，松手后显示原因；正式货物在通过后端检查后才更新。联动归位表示规划后的摆放状态，不表示现场可以直接抽走底托。
