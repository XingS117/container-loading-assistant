# 第 4 组：可核查的统计闭环

复用已部署的 Umami，不引入新的第三方服务。仅发送操作事件与计数，不发送 SKU、尺寸/重量明细、自由文本、模型 Key 或可读取任务结果的 job_id。

- 新增输入页开始与首次有效提交事件，input_id 表示一次输入流程；明确完成率是进入输入页到有效提交，不是每次键盘输入的校验率。
- 每次计算生成独立随机 attempt_id；开始/成功/失败/超时、后续方案切换/调整/打印请求/反馈均关联该 attempt_id。重复计算有不同标识，历史结果保留原标识并注明历史来源。旧历史无标识则明确 legacy。
- 前端结构化白名单过滤事件数据，统计服务失败不得阻断计算。保留耗时、错误类别、三目标、少装/调整计数与筛选条件。
- 文档提供去重、分母、反馈反复切换取最后一次、打印点击不等于实际打印等口径；已接收上报与后台报表/真实改善分开验收。
- 单元测试关联/过滤/失败隔离；浏览器真实检查上报请求和接收状态。无权限访问统计报表时如实记录缺口，不能用本机测试推断用户满意度改善。
