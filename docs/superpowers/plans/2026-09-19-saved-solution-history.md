# 完整方案与调整历史

目标：保留既有本机订单，支持刷新恢复计算结果、已应用人工调整、未装清单、锁定和当前方案，并可查看或复制历史版本。

沿用 React 与 localStorage，无新依赖。SavedOrder 扩展可选 response/workspace/preferredProfile，工作台只在应用后保存，保存原始三方案及各方案调整覆盖层以保留恢复原始布局能力。不保存 AI Key 或三维截图。订单名称不再作为覆盖标识。自动计算/应用/恢复原始布局各新增版本；切换方案只更新当前版本的选择状态。最多保留 10 个版本，满额拒绝新保存并提示删除旧版本，不静默删除历史。失败保留内存结果和原存储，明确提示未保存。

刷新使用输入草稿中的已保存版本 ID 恢复。回到输入或复制历史为新订单时清除该关联，不把旧方案误配给新货物。输入页和结果页都能查看历史；复制仅复制输入，不把旧结果当新计算。删除指定版本需要页面确认，删除不影响正在查看的内存布局。恢复是历史快照，不宣称按当前规则重新审核。
