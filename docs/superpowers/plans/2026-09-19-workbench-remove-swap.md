# 人工调整移出与交换实现计划

目标：接续已批准的编辑缺项，支持移出单件转未装清单、安全交换两件位置，并保持订单与打印数量一致。

架构：沿用 LayoutWorkbench 的草稿、整步撤销和服务端 reviewLayout。workbench.ts 增加原子移出与单件交换；订单 cargoItems 不变。每次变更通过几何预检和后端承重/朝向/必装规则后才写入历史。应用时按复核后的 placements 重新统计件数，现有结果清单和打印直接复用。

取舍：不删除订单、不放开悬空、不改变尺寸/重量/朝向。移出单件后，原上层按现有落位规则向下归位；任何锁定件需位移则整次拒绝。必装货物不能移出，须回订单明确变更必装约束。交换只交换两件的 XYZ，保留各自身份与朝向；不自动重排其他货物或强行塞入不匹配空间。移出可撤销/重做或恢复原方案，本轮不增加任意未装件插入功能。

- [x] 1. 安全移出：workbench.ts、LayoutWorkbench.tsx 及测试；验证底层移出上层落位、空布局、锁定阻止、必装阻止、失败原子性、撤销恢复。
- [x] 2. 单件交换：选择交换对象并确认；测试稀疏编号、不同 SKU/同 SKU、尺寸身份保留、边界/碰撞/支撑拒绝、锁定与服务端承重拒绝。
- [x] 3. 数量闭环：未装汇总、应用后 loaded_counts/unloaded_counts、警示与打印一致；原订单数量和其他方案不变。后端真实复核测试覆盖空/部分布局与必装缺失。
- [x] 4. 全量测试/构建、浏览器真实编辑与打印、GitHub 推送、备份部署、线上验证。
