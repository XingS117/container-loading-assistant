# 装柜系统升级优化设计规格

日期：2026-09-13
状态：已批准，待实施

## 目标

在暂不调整模型接入的前提下，提高一次任务完成率、布局可信度和仓库执行效率。系统必须保留本地物理校验作为最终裁决，任何策略建议都不能生成越界、碰撞、悬空或超载布局。

## 用户流程

1. 用户进入快速开始，选择柜型、导入 Excel 或打开测试案例。
2. 系统在计算前给出数据质量报告，用户可按字段修正错误。
3. 用户选择一个目标：高装载率、优先稳定、优先易操作。
4. 系统展示计算阶段、耗时和当前状态。
5. 结果页并列展示三套方案、目标达成情况、风险解释和推荐方案。
6. 用户可打印装载清单；后续版本可锁定、调整并局部重算。

## 方案策略

- `high_fill`：优先件数和空间利用率，在物理约束满足时允许更高的操作复杂度。
- `stable`：优先连续支撑、重心和左右前后平衡，抑制上层大空洞和悬空。
- `easy`：优先区域连续性、装载顺序、搬运距离和 SKU 切换次数，可明确牺牲少量件数。

每套方案必须输出目标、硬约束、未满足的软目标及指标变化，例如“少装 2 件，支撑连续性提高 18%”。

## 布局质量

在既有校验基础上增加可解释指标：大空洞数量与面积、上层支撑连续率、重心偏移、区域碎片度、SKU 切换次数和预计搬运距离。评分只能在合法候选中排序；局部空隙若不影响支撑和稳定性，应标记为可接受，并解释原因。

## 结果交付

第一阶段输出柜门到柜尾的装载步骤、货物编号、数量、方向和注意事项，并保留 3D、俯视、侧视、分层视图及打印/PDF。告警必须能定位到具体货物或区域。

## 可用性与错误处理

普通用户不应被要求配置模型、供应商或 API Key。计算失败时显示可理解的原因、已完成阶段和下一步操作；若存在可用的本地安全结果，应明确标注其来源和限制。输入错误必须定位到字段，不能只显示整体失败文本。

## 衡量标准

- 新用户可通过测试案例完成一次计算。
- 缺失字段和单位错误能在提交前定位。
- 三套方案均展示目标达成度和风险说明。
- 结果中的非法布局数为零。
- 方案切换、导出、失败和用户反馈可统计。
- 真实测试案例中，大空洞、支撑不足和用户手动调整次数持续下降。
