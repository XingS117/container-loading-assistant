## 九、风险与坑（提前预警）

### 坑 1：知乎/小红书硬广被限流

**症状**：账号发带网址的笔记，限流 0 阅读
**对策**：
- 链接放在评论区或主页简介，**不在正文出现**
- 内容 80% 干货 + 20% 工具植入，不要「硬推」
- 第一周只发干货不植入链接，养账号权重

### 坑 2：跨平台同步内容被识别

**症状**：知乎答案复制到小红书，直接限流
**对策**：
- **每个平台独立加工**，不要 Ctrl+C / Ctrl+V
- 知乎偏深度，小红书偏图文，公众号偏长文，平台调性不同

### 坑 3：只追阅读量不追转化

**症状**：阅读量破万，网站 UV 纹丝不动
**对策**：
- 把「生成方案次数」设为北极星指标
- Umami 事件追踪每个关键动作
- 每周复盘「平台 UV → 网站 UV → 生成方案」的转化漏斗

### 坑 4：内容产出跟不上消耗

**症状**：小红书 1 周发 1 篇，数据没起色就放弃
**对策**：
- 提前准备「内容池」：从 docs/ 评测 + 装柜案例挖 30+ 篇素材
- 每周固定 3h 写公众号深度文（一次写 2 周的量）
- 小红书和知乎基于素材池二次加工

### 坑 5：SEO 不做，等于把主动搜索用户送给竞品

**症状**：搜「装柜软件」看不到你的网站
**对策**：
- W1 必做：百度站长平台注册 + sitemap 提交
- W2 必做：官网 TDK 优化 + 至少 3 篇长尾内容页（40HQ 装柜案例等）
- 这是 **6 个月后决定流量天花板** 的关键，今天不投未来没饭吃

### 坑 6：忽略 Umami 配置

**症状**：没有数据，无法判断流量来源和质量
**对策**：
- 确认 Umami website_id 已配置并启用
- 给每个平台的引流链接加 UTM 参数
- 每周看一次「来源 - 转化」漏斗
