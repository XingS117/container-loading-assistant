# 人工调整交互与约束验证

本轮范围：压缩反馈选项、上移结果画布、吸顶方案标签；约束人工移动与旋转，保持原始货物尺寸不变。

## 实现

- 反馈复选框固定为 15px，标签支持整块点击及选中状态；详细指标默认折叠，反馈与 AI 说明移到画布下方。
- 拖动仅允许在当前高度平移，按整组边界限位；新增按当前长宽加间隙平移、水平旋转 90°、放回底层按钮。
- 修改先经过前端边界、碰撞、间隙、完整支撑检查，再通过后端朝向、承重、层数等规则复核后写入草稿。失败保留原布局，也禁止抽走上层支撑。
- 窄屏侧栏在画布区域内展开，不覆盖顶部操作按钮。

## 边界

约束检查针对最终摆放状态，不模拟叉车通路、搬运全过程或运输动态稳定性。当前旋转为货物允许的正交朝向。实际装卸仍需按现场条件复核。
