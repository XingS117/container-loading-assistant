哪个更划算？

① 按体积选

  • 货物体积 < 28 m³ → 选 20GP（剩余空间浪费少）
  • 货物体积 28-58 m³ → 选 40GP
  • 货物体积 58-66 m³ → 选 40HQ（多出 8 m³ 高度）
  • 货物体积 > 66 m³ → 考虑多柜或 45HQ

② 按重量选

  • 20GP 最大载重 21.5 吨
  • 40GP 最大载重 26.5 吨
  • 40HQ 最大载重 26.5 吨
  • 重货优先看重量限制（很多 40HQ 装不满是因为重量到顶了，不是体积）

③ 按运费选

海运运费按柜计价。2026 年参考价格（中国出口到美西）：

  • 20GP：约 1500-2500 USD
  • 40GP：约 2500-4000 USD
  • 40HQ：约 2700-4300 USD（比 40GP 贵约 200-300 USD）

40HQ 比 40GP 贵约 200-300 USD，但多装 8 m³。如果货物需要顶部那 30 cm 高度，40HQ 划算；如果装不满顶部，40GP 更划算。

④ 关键判断公式

如果你的货物 体积 ≥ 60 m³ 或能堆 2 层以上，40HQ 通常更划算。

如果你的货物 体积 ≤ 55 m³ 或只能单层摆，40GP 通常更划算。

常见误区

  • 误区 1："40HQ 装得多所以一定更划算"——如果货物只能装一层，40GP 反而省运费
  • 误区 2："20GP 便宜就选 20GP"——实际装得少反而单位运费贵
  • 误区 3："我每次都发 40HQ"——柜型选择应该看订单货量，不是惯性
